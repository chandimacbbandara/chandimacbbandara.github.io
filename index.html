About

I'm an IT undergraduate at SLIIT specialising in Data Science, with a passion for full-stack software engineering, applied machine learning, and intelligent system design. I work at the intersection of code and data — building things that are fast, purposeful, and grounded in real problems.

My background spans web and mobile development (Spring Boot, React Native), classical ML (TensorFlow, scikit-learn), and modern AI tooling — RAG pipelines, LangChain, HuggingFace, FAISS. I find the whole stack interesting, from database schema to model evaluation to the interface layer on top.

I care about software that solves real problems. My projects include AI-powered HR tools, computer vision systems for vehicle damage detection, student concern management platforms, and predictive models for mental health risk detection.
