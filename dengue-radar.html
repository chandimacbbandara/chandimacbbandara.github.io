DengueRadar — Real-Time Dengue Risk Mapping

AI-powered dengue outbreak prediction and interactive risk mapping for public health decision-making.

DengueRadar is a full-stack AI platform that predicts dengue fever risk across geographic zones using machine learning models trained on historical case data, weather patterns, and environmental factors. Built as a team entry for the Data Odyssey 2026 inter-university competition — where we earned 2nd Runners Up.

  • Interactive choropleth map with real-time risk level visualisation per district.
  • ML-based outbreak prediction using weather, humidity, and historical dengue data.
  • REST API backend serving risk scores and trend analysis to the frontend.
  • Public health dashboard with weekly forecasts and alert threshold indicators.
  • Responsive design for field health workers on mobile devices.
React Node.js Python Machine Learning Leaflet.js REST API Express
Live Demo → GitHub

Project Overview

DengueRadar was built to address a real public health challenge in Sri Lanka — dengue outbreaks that are often difficult to predict and respond to quickly. Our team leveraged machine learning and geospatial data to create an early-warning tool that health authorities and the public can use to understand outbreak risk in their area.

The platform ingests weather data (temperature, rainfall, humidity), historical dengue case counts, and population density to generate district-level risk scores on a weekly basis. These scores are displayed on an interactive map with clear colour-coded risk levels (Low → Critical).

Key Features

  • Interactive Leaflet.js map with district-level dengue risk heat zones.
  • Trained ML model predicting outbreak probability based on weather features.
  • Real-time data refresh — risk scores updated as new environmental data arrives.
  • Time-series charts showing case trends and rainfall correlations.
  • Mobile-responsive design for on-the-ground health workers.
  • Alert system for districts crossing high-risk thresholds.

Tech Stack

  • Frontend: React.js, Leaflet.js, Chart.js
  • Backend: Node.js, Express.js REST API
  • ML / Data: Python, Scikit-learn, Pandas
  • Maps: Leaflet.js with GeoJSON district boundaries
  • Deployment: Self-hosted VPS (145.223.22.182:3000)

Competition & Award

We participated in Data Odyssey 2026, the premier inter-university data science competition and exhibition organised by the AI & Data Science Club at General Sir John Kotelawala Defence University (KDU), Sri Lanka. Competing against teams from multiple universities, our DengueRadar platform was awarded 2nd Runners Up — recognising the project's innovation, real-world applicability, and technical execution.
